# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Hexman, please **do not** open a
public GitHub issue.

Instead, report it privately using one of the following:

- [GitHub Security Advisories](../../security/advisories/new) for this
  repository (preferred)
- Email dawidpolakowski@gmail.com

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof of concept
- Any relevant logs, screenshots, or affected versions

We'll acknowledge your report as soon as possible and keep you updated as the
issue is investigated and resolved. Please give us reasonable time to address
the issue before any public disclosure.

## Supported Versions

Hexman is currently pre-release. Until a first stable release is tagged,
security fixes are applied to the `main` branch only.
